    How FanSignal works

    01 · Observe

    Import exported Google Trends search-interest data, or use the illustrative demo.

    02 · Interpret

    Compare the latest four observations with the previous four, in index points.

    03 · Recommend

    Apply transparent momentum thresholds to suggest a test and relevant validation metrics.

    FanSignal is an additional product prototype layered on the Sports Fan Engagement Dashboard research project. Import Google Trends CSV exports directly; files are processed locally in your browser. Google Trends is not connected through a live API. Data source: Google Trends. No live API, event attribution, or conversion measurement is claimed.
